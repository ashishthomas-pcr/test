# Ecommerce React App

This project is a simple React-based ecommerce application created with [Vite](https://vitejs.dev/).

## Available Scripts

```bash
npm install    # install dependencies
npm run dev    # start development server
npm run build  # build for production
npm run preview # preview built app
```

The app includes placeholder pages for:

- Home
- Products
- Product details
- Cart
- Checkout

These pages are just placeholders and can be expanded later.
